Class VirtualIPOperations

The Network Management API includes operations for managing the Virtual IPs for your deployment. NOTE: An instance of this class is automatically created for an instance of the [NetworkManagementClient] {@link NetworkManagementClient~NetworkManagementClient}. See [virtualIPs] {@link NetworkManagementClient~NetworkManagementClient#virtualIPs}. Initializes a new instance of the VirtualIPOperations class.
