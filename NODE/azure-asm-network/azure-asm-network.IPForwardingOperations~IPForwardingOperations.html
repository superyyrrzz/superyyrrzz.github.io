Class IPForwardingOperations

The Network Management API includes operations for managing the IP Forwarding for your roles and network interfaces in your subscription. NOTE: An instance of this class is automatically created for an instance of the [NetworkManagementClient] {@link NetworkManagementClient~NetworkManagementClient}. See [iPForwarding] {@link NetworkManagementClient~NetworkManagementClient#iPForwarding}. Initializes a new instance of the IPForwardingOperations class.
