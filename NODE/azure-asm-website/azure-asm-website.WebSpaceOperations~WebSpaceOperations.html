Class WebSpaceOperations

Operations for managing web spaces beneath your subscription. NOTE: An instance of this class is automatically created for an instance of the [WebSiteManagementClient] {@link WebSiteManagementClient~WebSiteManagementClient}. See [webSpaces] {@link WebSiteManagementClient~WebSiteManagementClient#webSpaces}. Initializes a new instance of the WebSpaceOperations class.
