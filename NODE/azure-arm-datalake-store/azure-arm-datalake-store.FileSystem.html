concurrentAppend(accountName, filePath, streamContents, options, callback)

Appends to the specified file. This method supports multiple concurrent appends to the file. NOTE: ConcurrentAppend and normal (serial) Append CANNOT be used interchangeably; once a file has been appended to using either of these append options, it can only be appended to using that append option. ConcurrentAppend DOES NOT guarantee order and can result in duplicated data landing in the target file.

append(accountName, directFilePath, streamContents, options, callback)

Appends to the specified file. This method does not support multiple concurrent appends to the file. NOTE: Concurrent append and normal (serial) append CANNOT be used interchangeably. Once a file has been appended to using either append option, it can only be appended to using that append option. Use the ConcurrentAppend option if you would like support for concurrent appends.

Declaration
function append(accountName, directFilePath, streamContents, options, callback)
Parameters
Type Name Description
string accountName

The Azure Data Lake Store account to execute filesystem operations on.
string directFilePath

The Data Lake Store path (starting with '/') of the file to which to append.
object streamContents

The file contents to include when appending to the file.
object options

Optional Parameters.

Properties
Type Name Description
number offset

The optional offset in the stream to begin the append operation. Default is to append at the end of the stream.
string syncFlag

Optionally indicates what to do after completion of the append. DATA indicates more data is coming so no sync takes place, METADATA indicates a sync should be done to refresh metadata of the file only. CLOSE indicates that both the stream and metadata should be refreshed upon append completion. Possible values include: 'DATA', 'METADATA', 'CLOSE'
