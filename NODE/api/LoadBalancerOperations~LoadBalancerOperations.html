beginCreating(serviceName, deploymentName, parameters, callback)

Add an internal load balancer to a an existing deployment. When used by an input endpoint, the internal load balancer will provide an additional private VIP that can be used for load balancing to the roles in this deployment.

Declaration
function beginCreating(serviceName, deploymentName, parameters, callback);
Parameters
Type Name Description
string serviceName

The name of the service.
string deploymentName

The name of the deployment.
LoadBalancerCreateParameters parameters

Parameters supplied to the Create Load Balancer operation.

Properties
Type Name Description
string name

Name of the load balancer.
FrontendIPConfiguration frontendIPConfiguration

The configuration for the virtual IP address (VIP) this load balancer provides.

Properties
Type Name Description
string type

The type of the VIP provided by this load balancer. Currently, only 'Private' is supported. This will create load balancing services on a private VIP.
string subnetName

If the deployment exists inside a virtual network, a subnet of that virtual network must be specified for the load balancer. The VIP managed by the load balancer will then be an IP address out of this subnet. If the deployment exists outside of a virtual network, no subnet can be specified and the private VIP will be an IP address from the general private address pool.
string staticVirtualNetworkIPAddress

If the deployment exists inside a virtual network, a specific address from the load balancer subnet can be specified. The VIP for the load balancer will then be this specific IP address. If a static virtual network IP address is provided, the SubnetName element of the load balancer must be specified as well. If the deployment exists outside of a virtual network, no static virtual network IP address can be specified.
function callback
Returns
