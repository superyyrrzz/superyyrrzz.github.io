Gets or sets type of Rule. Possible values: Inbound (to be evaluated against ingress traffic), Outbound (to be evaluated against egress traffic).

Gets or sets Priority. Value from 100 – 4096.

Gets or sets Action. Allow/Deny. Whether to allow or deny traffic.
