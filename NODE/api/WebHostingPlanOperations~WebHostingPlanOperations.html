getHistoricalUsageMetrics(webSpaceName, webHostingPlanName, parameters, callback)

You can retrieve historical usage metrics for a site by issuing an HTTP GET request. (see http://msdn.microsoft.com/en-us/library/windowsazure/dn166964.aspx for more information)

Declaration
function getHistoricalUsageMetrics(webSpaceName, webHostingPlanName, parameters, callback);
Parameters
Type Name Description
string webSpaceName

The name of the web space.
string webHostingPlanName

The name of the web hosting plan.
WebHostingPlanGetHistoricalUsageMetricsParameters parameters

Parameters supplied to the Get Historical Usage Metrics Web hosting plan operation.

Properties
Type Name Description
array metricNames

Specifies a comma-separated list of the names of the metrics to return. If the names parameter is not specified, then all available metrics are returned.
date startTime

The starting time of the metrics to return. If this parameter is not specified, the beginning of the current hour is used.
date endTime

The ending time of the metrics to return. If this parameter is not specified, the current time is used.
string timeGrain

The grain at which the metrics are returned. Supported values are PT1M (minute), PT1H (hour), P1D (day).
boolean includeInstanceBreakdown

Flag which specifies if the metrics for each machine instance should be included. For sites that run on more than one machine this could be useful to identify a bad machine.
