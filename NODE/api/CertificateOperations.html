add(certificate, options, callback)

Declaration
function add(certificate, options, callback);
Parameters
Type Name Description
object certificate

The certificate to be added.

Properties
Type Name Description
string thumbprint

The X.509 thumbprint of the certificate. This is a sequence of up to 40 hex digits (it may include spaces but these are removed).
string thumbprintAlgorithm

The algorithm used to derive the thumbprint. This must be sha1.
string data

The base64-encoded contents of the certificate. The maximum size is 10KB.
string certificateFormat

The format of the certificate data. Possible values include: 'pfx', 'cer', 'unmapped'
string password

The password to access the certificate's private key. This is required if the certificate format is pfx. It should be omitted if the certificate format is cer.
object options

Optional Parameters.

Properties
Type Name Description
object certificateAddOptions

Additional parameters for the operation

Properties
Type Name Description
number timeout

The maximum time that the server can spend processing the request, in seconds. The default is 30 seconds.
string clientRequestId

The caller-generated request identity, in the form of a GUID with no decoration such as curly braces, e.g. 9C4D50EE-2D56-4CD3-8152-34347DC9F2B0.
boolean returnClientRequestId

Whether the server should return the client-request-id in the response.
date ocpDate

The time the request was issued. If not specified, this header will be automatically populated with the current system clock time.
object customHeaders

Headers that will be added to the request
