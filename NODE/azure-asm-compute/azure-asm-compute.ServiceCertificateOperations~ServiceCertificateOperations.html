Class ServiceCertificateOperations

Operations for managing service certificates for your subscription. (see http://msdn.microsoft.com/en-us/library/windowsazure/ee795178.aspx for more information) NOTE: An instance of this class is automatically created for an instance of the [ComputeManagementClient] {@link ComputeManagementClient~ComputeManagementClient}.
