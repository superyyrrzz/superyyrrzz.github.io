Class ApnsService

The ApnsService class is used to send notifications using the Apple Push Notification Service (APNS). This service is used to communicate with iOS device.

Constructors

ApnsService(notificationHubService)

Creates a new ApnsService object using the specified <xref:NotificationHubService> object.

Note: An instance of this object is created automatically when a <xref:NotificationHubService> object is created. See <xref:NotificationHubService#apns>.

send(tags, payload, callback)

Sends an APNS notification.

Declaration
function send(tags, payload, callback)
Parameters
Type Name Description
string tags

A single tag or tag expression. If null it will broadcast to all registrations in this hub
object payload

The message's JSON payload as specified below. If the payload is a string, follow the APNS format as in https://developer.apple.com/library/ios/documentation/NetworkingInternet/Conceptual/RemoteNotificationsPG/Chapters/ApplePushService.html#//apple_ref/doc/uid/TP40008194-CH100-SW1

Properties
Type Name Description
date expiry

The expiration date. (in W3C DTF, YYYY-MM-DDThh:mmTZD (e.g. 1997-07-16T19:20+01:00))
object aps

If the 'aps' member is provided, the object is delivered to APNS as-is after expiry is processed. The object is assumed to follow the APNS format at https://developer.apple.com/library/ios/documentation/NetworkingInternet/Conceptual/RemoteNotificationsPG/Chapters/ApplePushService.html#//apple_ref/doc/uid/TP40008194-CH100-SW1
number badge

If the 'aps' member is not provided, the number to display over the app icon.
string alert

If the 'aps' member is not provided, the alert text.
string sound

If the 'aps' member is not provided, the sound file name.
object payload

If the 'aps' member is not provided, the payload object that contains the notification text.
function callback

error will contain information if an error occurs; otherwise, response will contain information related to this operation.
