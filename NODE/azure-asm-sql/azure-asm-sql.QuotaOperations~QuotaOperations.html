Class QuotaOperations

The Azure SQL Database Management API includes operations for getting Azure SQL Database Server quotas. Specifically, using the APIs you can get a specific quota or list all of the quotas for the Azure SQL Database Server. NOTE: An instance of this class is automatically created for an instance of the [SqlManagementClient] {@link SqlManagementClient~SqlManagementClient}. See [quotas] <xref:SqlManagementClient~SqlManagementClient#quotas>. Initializes a new instance of the QuotaOperations class.
