Class ServerOperations

Contains methods to allow various operations on Azure SQL Database Servers. NOTE: An instance of this class is automatically created for an instance of the [SqlManagementClient] {@link SqlManagementClient~SqlManagementClient}. See [servers] <xref:SqlManagementClient~SqlManagementClient#servers>. Initializes a new instance of the ServerOperations class.
