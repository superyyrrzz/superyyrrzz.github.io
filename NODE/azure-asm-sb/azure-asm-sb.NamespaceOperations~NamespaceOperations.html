Class NamespaceOperations

The Service Bus Management API includes operations for managing Service Bus namespaces. NOTE: An instance of this class is automatically created for an instance of the [ServiceBusManagementClient] {@link ServiceBusManagementClient~ServiceBusManagementClient}. See [namespaces] {@link ServiceBusManagementClient~ServiceBusManagementClient#namespaces}. Initializes a new instance of the NamespaceOperations class.
