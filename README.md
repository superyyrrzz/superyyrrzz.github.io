# superyyrrzz.github.io

Personal blog of Renze Yu. Built with [Jekyll](https://jekyllrb.com/) and
the [minimal-mistakes](https://github.com/mmistretta/minimal-mistakes) theme,
deployed by GitHub Pages from `master`.

## Local preview

```bash
bundle install
bundle exec jekyll serve --livereload
# http://127.0.0.1:4000
```

## Writing a post

Drop a Markdown file in `_posts/` named `YYYY-MM-DD-slug.md` with front matter:

```yaml
---
title: "Post title"
date: 2026-05-27
tags: [tag-one, tag-two]
---
```
